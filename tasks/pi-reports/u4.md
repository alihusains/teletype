## What changed, per file

- `ui/src/App.tsx` (U4-4, U4-5, U4-6, U4-7)
  - Command Mode nav icon `sparkles` -> `zap` (matches the screen's own identity icon).
  - The three toasts now render inside one fixed stack container (`bottom: 26`, flex column, gap 10, `width: max-content`, `maxWidth: 520`). Each toast keeps its exact previous styling minus the fixed positioning, so a single toast looks identical to before and two or three stack vertically instead of overlapping.
  - Skip toast timer moved into a `useRef`; a new message clears the pending timer before arming a fresh 6 s one.
  - `navStatus` gained an explicit `runtime.speech.state === "error"` branch: warning-colored "Model error" with the backend detail as title, matching the shared StatusRow treatment.
- `ui/src/components/CrashNotice.tsx` (U4-2): inline SVG replaced with `<Icon name="alert" size={16} />`; added the Icon import. `open_crash_dir` verified to exist and be registered (`crates/teletype-desktop/src/lib.rs:1393`), so the Details button is live.
- `ui/src/settings/primitives.tsx` (U4-3): `FrozenNotice` glyph replaced with `<Icon name="info" size={13} />` (inherits the warning color via currentColor); added the Icon import.
- `ui/src/components/FixesCard.tsx` (U4-1): deleted. Verified unreferenced by a full-tree grep before and after removal; no test references it.

## Verified live (not dead)

Every control in the owned files was checked against `crates/teletype-desktop/src/commands/` and the `lib.rs` invoke handler list:

- App.tsx: `dismiss_pending_notice`, `recovery_status`, `recover_last_dictation`, `discard_recovery`, `undo_learned`, `get_settings`, `get_permissions` all exist and are registered.
- CrashNotice: `open_crash_dir` exists. Dismiss is local-only by design: the backend consumes the crash report on first read (`crash.rs::crash_notice` renames it to `*.json.shown`), so the one-time banner cannot reappear after a session-only dismissal.
- DownloadProgress: `pause_download`, `resume_download`, `cancel_download` exist. The `kind === "llm"` pause gate is correct, not a dead control: `resume_download` delegates to `download_model` (LLM path only), so a paused speech download could not be resumed and the UI correctly hides the control.
- TabRail, StateRows, ImpactCard, LatencyPanel: controlled/display-only; consumers (DictionaryScreen, the list screens, HomeScreen, InsightsScreen) pass real handlers and data.
- Icon.tsx: all 51 `IconName` entries have a `PATHS` mapping (enforced by the `Record<IconName, ReactNode>` type).
- `settingsSearch.ts`: pure matcher, 9 existing unit tests pass unchanged.
