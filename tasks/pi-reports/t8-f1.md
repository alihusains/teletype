# t8-f1: strip the echoed control line on the 0.8B Polish path

Worktree: `/Users/a.sorathiya/Documents/Ali/teletype-wt/t8-qwen08`
(branch `fix/qwen08-prompts`). Date: 2026-11-10.

## Summary

The 0.8B can echo the control line verbatim as the first line of its Polish
output (finding F1 in `t8.md`, deterministic 3/3 at temp 0), and nothing
stripped it, so the user saw it in their text. `qwen08_polish_postprocess`
now removes at most one leading line that is the control line or a near-miss
echo of it, before the existing prose shaping. Two regression tests cover
the verbatim and the mangled shape; both were red before the fix and green
after.

## What changed, per file

### `crates/teletype-core/src/transforms/engine.rs` (only code file touched)

1. New pure helper `strip_echoed_control_line` (engine.rs:332, fn at
   engine.rs:338). Takes the model output and the `PromptContext`. If the
   first line, trimmed, equals `ctx.s1_control.control_line()`, or is a
   near-miss echo (starts with `[Styling:` and contains `[Structure:` and
   `[Context:`), it removes that one line plus the newline after it and
   returns the rest. Never removes more than one leading line; the rest of
   the text is never touched.
2. `qwen08_polish_postprocess` (fn at engine.rs:358) now calls the helper
   first and runs the existing prose shaping (bullet fold, lead
   capitalization, British-spelling fallback) on the stripped text. The
   doc comment was updated to list the third repair.
3. Two new tests in the existing `mod tests`, both using the existing
   `Qwen08Recorder` with the exact F1 probe input
   ("for the party i need to buy milk, buy eggs, buy bread, and buy cheese")
   and the matching control context (casual / lists / general):
   - `qwen08_polish_strips_echoed_control_line` (engine.rs:2359): reply is
     the verbatim control line plus the polished sentence. Asserts
     `result.transformed`, text does not start with `[`, does not contain
     `[Styling:`, and the body survives.
   - `qwen08_polish_strips_mangled_control_line_echo` (engine.rs:2401):
     near-miss reply with a capital C in `[Styling: Casual]`. Same
     assertions.
