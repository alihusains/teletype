## What was changed, per file

### ui/src/screens/HomeScreen.tsx
- Title `div` -> `h2` (U1-1). `.tt-screen-title` sets `margin: 0`, so the
  h2 default margin cannot shift the layout.
- HistoryRow: removed `role="button"`/`tabIndex` (U1-2); the row is a plain
  display row, the copy/delete buttons are the interactive elements.
- Copy button (U1-3): now awaits `writeText`; `copyState` idles to "copied"
  (1.2 s) or "failed" (2.4 s) exactly like DictationScreen's copy. Icon and
  title/aria-label follow the state (check/success, copy/danger).
- Delete button (U1-4): gated by `confirmDialog("Delete this dictation?")`
  (same message/title as DictationScreen), disabled while in flight, and a
  rejected `delete_dictation_entry` renders "Delete failed: {error}" with
  Retry and Dismiss inside the row instead of vanishing.
- Added imports: `confirmDialog` (lib/dialogs), `errorMessage` (lib/errors).

### ui/src/screens/DictationScreen.tsx
- Error state of the file-transcription box (U1-5): the status line now reads
  "Transcription failed"; the red detail line keeps
  "The file was not transcribed: {error}". The raw error appears exactly
  once.

### ui/src/screens/NotetakerScreen.tsx
- `refresh` (U1-7): a rejected `list_notes` sets `loadError`; the list pane
  shows "Notes could not be read." with the error and a "Try again" button
  (role="alert") instead of "No notes yet.". A successful read clears it.
- `toggleEnabled` (U1-6): still flips optimistically, but rolls the checkbox
  back when `get_settings` or `save_settings` rejects.
- Added import: `errorMessage` (lib/errors).

### ui/src/test/homeStates.test.tsx (exclusively covers HomeScreen)
- 4 new tests in "HomeScreen history row actions": Copied only after a
  successful write; Copy failed (not Copied) on a rejected write; no
  `delete_dictation_entry` call when the confirm is declined; rejected delete
  keeps the row and shows the error with Retry. `vi.unstubAllGlobals()` added
  to afterEach for the navigator clipboard stub.

### ui/src/test/dictationStates.test.tsx (exclusively covers DictationScreen)
- 1 new test in "DictationScreen file error": a rejected `transcribe_file`
  shows "Transcription failed" and the raw error exactly once (guards U1-5).

### ui/src/test/notetakerScreen.test.tsx (exclusively covers NotetakerScreen)
- 2 new tests: rejected `list_notes` shows the retry row, not "No notes
  yet."; the routing toggle rolls back when `save_settings` rejects (asserts
  the optimistic flip first so a dead toggle cannot pass).

### Not changed (verified live, no defect)
- DictationScreen: search, Choose file (dialog + `transcribe_file`), Cancel,
  card copy/reveal/delete, Show-changes toggle, AudioPlayer play/seek.
- DictationCard: expand/collapse, copy, Show in Finder/Explorer, Delete,
  Show-changes (Toggle from settings/primitives, u4-owned, used correctly).
- AudioPlayer: play/pause, waveform seek (click + keyboard), load/error
  states. `get_dictation_audio` exists in commands/history.rs.
- InlineDiff, waveform.ts, types.ts: pure rendering/logic, no controls.
- InsightsScreen: range buttons, custom date inputs, Retry, "See all time";
  all CTAs are correctly guarded by `onNavigate`.
- HomeScreen: Get a model / Start dictating / Try a transform (navigate),
  privacy-row dismiss (state + localStorage), ReadinessPanel (u4-owned).
