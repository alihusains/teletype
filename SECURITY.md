# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull
requests. Use GitHub's **Report a vulnerability** option in the repository's
Security tab when private vulnerability reporting is available. If it is not
available, contact the maintainer privately through the GitHub profile linked
from this repository.

Include the affected version or commit, the impact, and steps to reproduce.
Do not include real API keys, passwords, transcripts, or other private data in
the report.

There is no published response-time commitment. Please allow the maintainer
time to investigate before disclosing details publicly.
