Teletype — Third-Party Notices
==============================

This file lists the third-party components that Teletype bundles or links
against, together with their licenses. License attribution for each entry is
current as of the release in which it was added; re-verify when the component
is upgraded.

Conventions:
- "Direct dependency" = declared in the workspace Cargo.toml / per-crate
  Cargo.toml [dependencies] or in ui/package.json.
- Transitive dependencies: not listed individually. The full locked
  dependency tree (including versions and licenses via crates.io metadata)
  is reproduced by:
      cargo tree -e normal,build --prefix none
  and `npm ls --all` in ui/.
